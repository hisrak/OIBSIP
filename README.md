# OIBSIP

My work for the **Oasis Infobyte** Summer Internship Program (SIP).

- **Track:** Web Development & Designing
- **Level completed:** Level 1 (all 3 tasks)
- **Built with:** HTML5, CSS3 and vanilla JavaScript

## 📂 Projects

| # | Project | What it is | Tech | Folder |
|---|---|---|---|---|
| 1 | **NovaFit Landing Page** | A responsive, animated landing page for a fictional fitness app | HTML5, CSS3 | [WebDev-L1-LandingPage](WebDev-L1-LandingPage) |
| 2 | **Personal Portfolio** | My portfolio with skills, projects, internship experience, dark/light theme and English/Urdu | HTML5, CSS3, JavaScript | [WebDev-L1-PersonalPortfolio](WebDev-L1-PersonalPortfolio) |
| 3 | **ThermoLab Temperature Converter** | Converts Celsius, Fahrenheit and Kelvin with validation and an animated thermometer | HTML5, CSS3, JavaScript | [WebDev-L1-TemperatureConverter](WebDev-L1-TemperatureConverter) |

Each folder has its own `README.md` with features, screenshots and how to run it.

## ▶️ How to run any project

1. Clone this repository: `git clone https://github.com/hisrak/OIBSIP.git`
2. Open the project folder and double-click `index.html` (or use the VS Code **Live Server** extension).
